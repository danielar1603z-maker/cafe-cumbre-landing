# Café Cumbre — Landing Page

Landing page para una tostadora de café de especialidad ficticia en Medellín, Colombia. Proyecto de portafolio enfocado en diseño de interfaces.

## Demo

Abre `index.html` en tu navegador — no necesita instalación ni backend.

## Concepto de diseño

En vez de tarjetas de producto genéricas, cada café se presenta como una "ficha de catación" — el formato real que usan las tostadoras de especialidad para mostrar altura, variedad, proceso y notas de cata de cada lote. La idea fue que el diseño reflejara el producto real, no solo decorarlo.

## Funcionalidades

- Landing page completamente responsive (desktop, tablet, móvil)
- Menú de navegación con scroll suave a cada sección
- Menú móvil colapsable
- Diseño accesible: foco visible en elementos interactivos, animaciones reducidas si el sistema lo pide

## Tecnologías

- HTML5
- CSS3 (sin frameworks, con variables CSS para el sistema de color)
- JavaScript (vanilla, solo para el menú móvil)
- Google Fonts (Zilla Slab, Work Sans, JetBrains Mono)

## Qué aprendí construyendo este proyecto

- Diseño de un sistema de color y tipografía coherente desde cero
- Layouts con CSS Grid para estructuras editoriales (fichas, pasos de proceso)
- Diseño responsive con múltiples breakpoints
- Cómo un elemento visual (la ficha de catación) puede comunicar información real del negocio en vez de ser solo decoración
